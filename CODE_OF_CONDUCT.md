# Code of conduct

This project adopts the **[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)**
as its code of conduct. Everyone taking part in issues, pull requests, discussions and other
project spaces is expected to follow it.

In short: be respectful and constructive, assume good intent, and do not harass anyone. Never post
anyone's personal data, including customer data from a dealership.

## Reporting
Report unacceptable behavior to the maintainer, Gurkirat Singh Khaira (GitHub `Gurkirat-Khaira`).
Until a dedicated conduct contact address is published, use a
[private security advisory](../../security/advisories/new) and mark it "Code of conduct". Reports are
handled confidentially.

## Enforcement
The maintainer applies the Contributor Covenant's enforcement guidelines (correction, warning,
temporary ban, permanent ban).
