**Gotchas**
- **Workflow:** one branch and PR per task, squash-merged with the plan's commit title and an
  empty body. Ask the owner before each merge.
  - `gh pr edit` fails (GitHub GraphQL deprecation), so use `gh api` REST for PR bodies and merges.
  - `main` requires PRs plus passing checks: `lint, typecheck, test, build`, `secret scan (gitleaks)`
    and `CodeQL`. Update a stale PR branch with `gh api -X PUT …/pulls/N/update-branch`.
- **Force push is denied to Claude** by `.claude/settings.json`. The owner runs it with `!`.
- **The guard hook blocks any Bash command that mentions `.env`.** Write files that reference it
  with the Write tool.
- **Chainguard MinIO image:** has no grep, so `docker/minio/init.sh` matches with shell `case`.
- **drizzle-kit:** loads its config as CommonJS (`import.meta` is empty there).
- **Test database names:** DB tests drop and recreate `dms_test_*` databases. Two packages running
  DB tests at once will collide (see ADR 0005).
- **FORCE RLS applies to the owner role too.** Seed with `asOwner(dealerId, …)`.
- **Logger:** redaction is by key name. Never put PII in messages (`packages/core/CLAUDE.md`).
